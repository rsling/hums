# quantise moving an onset across the loop point, in a loop that is no
# multiple of the grid (docs/SCHEMA.md -> ClipPool / Clip).
#
# The grid is 480 ticks (1/8), the loop 1000. The candidate lines are the
# multiples of the grid up to the loop length, 0, 480 and 960, and the loop
# length itself, 1000, which stands for tick 0. No line is invented at 1440.
# The notes in child order:
#
#   pitch  stored  nearest line                       plays  length
#   72     990     1000 (10 away; 960 is 30 away):    0      100 -> off 100
#                  wraps to 0
#   60     0       on a line already                  0      50  -> off 50
#   64     980     960 and 1000 both 20 away:         960    100 -> off 1060,
#                  a tie goes down, no wrap                  60 into the next pass
#   67     700     480 (220 away; 960 is 260 away)    480    50  -> off 530
#
# The cc event at 990 is no note and stays at 990.
#
# The wrapped note 72 stands at tick 0 of the loop for every later rule: it
# is heard at the beginning of each pass, the first included, and not at 990.
# At tick 0 it shares the tick with note 60 and comes first, in child order.
#
# The placement covers 0 to 2000, two passes:
#
#   first pass   72 and 60 on at 0, 60 off at 50, 72 off at 100;
#                67 from 480 to 530; 64 on at 960; cc at 990
#   second pass  72 and 60 on at 1000, 60 off at 1050; 64 of the first pass
#                off at 1060; 72 off at 1100; 67 from 1480 to 1530; 64 on at
#                1960; cc at 1990; the placement ends at 2000 and cuts 64
