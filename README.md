# Hums – The Humane MIDI Sequencer

## What is Hums?

I own a purely hardware-based synthesizer setup. However, I never managed to go DAWless because I always hit some wall with hardware sequencers. On the other hand, DAWs suck because I don't need audio, loops, sampling, virtual synths, FX plugins and cluttered interfaces with tons of options within options. This is why I'll now spend tokens I'd otherwise leave unclaimed on this project: my dream sequencer. JUCE is what makes this possible.

## Timeline

As explained above, I only use tokens that would go to waste (from my perspective) otherwise. Other (more serious) projects get their tokens first. Furthermore, starting with Milestone 4, things will get messier and require significantly more iterations (both on the agentic side and the human side) – and I don't have a lot of time to waste on this. Expects a first sort of usable GUI app (drum sequencer view only) maybe by April 2027. If we get this far, then maybe we'll see a fully working (but buggy) app by October 2027 (or never).

## My role

I don't review code. I just make all decisions on the architecture, I review tests, and I do UI testing.
