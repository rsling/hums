# Hums – The Humane MIDI Sequencer

I own a purely hardware-based synthesizer setup. However, I never managed to go DAWless because I always hit some wall with hardware sequencers. On the other hand, DAW suck because I don't need audio, sampling, virtual synths, FX plugins and cluttered interfaces. This is why I'll now spend tokens I'd otherwise leave unclaimed on this project: my dream sequencer. JUCE is what makes this possible.

I don't review code, I just review tests and do UI testing.
